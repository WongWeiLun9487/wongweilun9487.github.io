Fiber Calculator
Type: Android Mobile Application
Programming Language: Java
Tools: Android Studio

This android mobile application developed for polytechnic students to learn about fiber optic.


This application included:
  • Equation
  • Calculation

Equation

This feature show the explanation about the power budget and the equaltion to calculater it.

Calculation

This feature included 3 different calculation which included
  • Fiber Length
  • Transmitter Power
  • Total Link Loss
